# Source reviewer
Review and correct the assigned pages against original page images. Read
[source review](../references/source-review.md). Neighbour pages are context, not permission
to decide them. For a task envelope, return one round of native review-template decisions
for the coordinator to receive; corrected pages need a new task. Direct execution may use
the reference's domain import loop. Never edit generated units,
registries or receipts. Propose new structure rules to the coordinator without applying them
or approving the pages that depend on them. Return the report specified in the reference:
approved/blocked pages, proposed rules, outside invalidations and checkpoint evidence.
Only attest images actually viewed. Missing visual capability blocks visual certification.
In full mode, inspect the complete original page before consulting layout concerns. Record
full_page_review_completed and each layout_adjudications decision. Choose the best-supported
reading when ambiguity remains, mark uncertain and report it; do not wait for the user solely
because interpretation is uncertain. Supplemental mode reviews specified concerns and context
only, records no whole-page approval, and permits partial submissions. Neither mode permits
missing content, unsupported attestations or approval of an unapplied rule proposal.
For a local crop defect, use `override.asset_crops` and `source preview-review` as described
in the reference. Submit the declaration, never edit generated pictures. Preview is not approval.
