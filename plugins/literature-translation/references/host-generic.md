# General compatibility
Use standard SKILL.md files and portable role instructions with the deterministic CLI.
A host with local subagents can dispatch the same task handoff; otherwise open a fresh
session for each worker. The coordinator resumes by inspecting task status and saved results.
Do not label same-context self-review independent.

Cursor and Qoder may use the thin literature-* agent definitions if their version supports
them. Keep their existing installation paths and user configuration. Their model selection
remains host-owned; unavailable controls are advisory. Native capabilities must be checked
instead of assuming that a compatible file format guarantees identical behavior.
Keep source/project state local. Cross-machine writers follow project-record.md.
