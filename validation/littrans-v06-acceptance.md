**当前状态：软件回归与隔离分发验收通过；64 个公式最终核验通过；8 个 batch 的 `complete` 与 `reading_complete` 均为 true。u05 已修订、三类独立审校复审通过且问题已 resolved。最终阅读布局的浏览器 DOM 检查与主审目视复核通过。以上均不是人类批准。**

### Windows 锁目录交接

完整回归曾发现并发外审的 `PermissionError`。随后通过真实 Windows 双线程复现：每线程尝试 1000 次项目锁进入，完成计数为 150 和 1000，失败堆栈指向 `project_write_lock` 中对 `.littrans-write-lock` 的 `mkdir()`，错误为 `WinError 5`。这是锁目录删除／重建交接期间的拒绝访问，不能用重复运行到通过来判定已解决。

修复仅对 Windows `mkdir` 的 `WinError 5` 在既定 deadline 内等待；未取得锁不会进入临界区，持续权限错误到期仍抛出原异常，其他平台或错误不被吞掉。确定性的暂时拒绝、持续拒绝、非目标错误测试以及真实线程互斥回归通过；相同双线程压力脚本修复后完成 1000／1000 次且无异常。

复现与修复证据分别为 `tmp/v06-qa62-project-lock-stress.log`、`tmp/v06-qa62-project-lock-fixed-stress.log` 和 `tmp/v06-qa62-lock-fixed.log`。

### 已知数学错误的审核关卡回归

测试覆盖共轭横线遗漏、嵌套下标被压平、两条递推式连写。原图保留对应特征，语法合法但有数学错误的候选不能自行成为已核验表达；独立审核的显式拒绝保留原图及其哈希。

这些测试是 **gate oracle**：拒绝结论由测试明确给定，用于验证审核与回退关卡。它们不测量模型是否能发现错误，不能计入公式识别准确率。译文记录中的未解决理解问题另由 QA 阻塞，并纳入依赖范围与缓存指纹；仅 LaTeX 尚未完成不属于理解不确定性。

## QASC 源内容保真保存

既定 24 页为评分页，另以第 115、150 页提供必要上下文，共 26 页完成源保存及目视复核。保留 453 个资产，包含整幅图和不能干净切分时的整行／区域回退；这些回退不是 LaTeX 转写成功。

最终样本中，**已知内容遗漏为 0、关键内容裁切为 0**。这是完成区域修正与目视复核后的结论，不是自动定位召回率 100%，也不是对全书零遗漏的证明。原式资产始终可回到来源；显式字形修正复制原 PDF 路径，不进行 OCR 或字符猜测，并考虑超出字体名义框的实际墨迹。
