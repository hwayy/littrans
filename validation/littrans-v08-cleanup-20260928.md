# LitTrans 0.8 cleanup audit

Build: `0.8.0-dev.2`, branch `dev/0.8`, 2026-09-28.

## Corrected

- Removed old skill reference redirects and empty directories; repaired remaining live links.
- Updated migration instructions to current skills, command names and coordinator-owned
  task reception. Updated release acceptance from seven old skills to four skills/seven roles.
- Removed fixed 0.7.6 filenames from local artifact installation examples.
- Fixed the ZIP distribution allowlist to include `roles/`. A regression builds both wheel
  and ZIP and checks actual packaged roles, current skills and the task protocol reference.
- Moved a provider-lock test from the relative `project/` path into its pytest temporary
  directory. Removed the release validator exception for that generated directory.
- Removed the empty plugin-local `project/` and `.scratch/` directories after checking that
  neither contained files. Added validation for skill directories missing `SKILL.md`.

## Retained deliberately

- Legacy CLI aliases are required throughout 0.8.x.
- Historical changelog/validation records and older-named regression tests document or test
  still-relevant behavior; an old filename alone is not evidence that a test is obsolete.
- The small fidelity workflow index preserves historical section paths without duplicating
  detailed contracts. Current skills load the domain references directly.
- Local environments, caches, `tmp/`, and user-owned `.claude/` and `.idea/` were not removed.
  No tracked cache, temporary, backup or generated bytecode files were found.

## Validation

52 tests passed: packaging/reliability, release validation and external review. These include
real local wheel/ZIP builds. Release metadata/link/schema validation, plugin Ruff and
`git diff --check` passed. Active migration, skill and agent instructions contain no retired
skill calls. The full 1255-pass suite from dev.1 was not repeated for this focused cleanup;
native-host pilots remain pending as recorded in the original local acceptance report.
