# 外部 CLI 审阅与宿主复审验收

## 实现范围

所有协调宿主通过独立 CLI 进程完成外部审阅。配置采用固定 `reviewer` 和单层有序 `fallbacks`，每项独立指定模型和可选思考强度。只有调用失败才进入回退链；有效的内容意见交给宿主独立复审。

新增 `codex-cli` 和 OpenCode 2.x 的 `opencode-cli`。保留 Claude、Antigravity 和 Cursor 驱动。实际模型取自 CLI 元数据；实际强度不可得时保留未知值。新进程清除继承的宿主会话标记，保留认证环境。

`external-recheck` 使用现有任务框架和审核角色。复审包只包含疑难条目及必要依赖，隐藏原意见。协调者通过 `external-adjudicate` 记录两份意见的引用、逐条决定和证据理由。复审缺失、过期或裁决仍不确定时，外部批准保持阻塞。

移除了最少使用次数选择、审阅者预留、外部第二意见调度、宿主结果导入和 `literature-external-reviewer` 角色。历史记录仍可读取；旧宿主子智能体结果不能满足外部门槛。迁移命令支持预览、原文件备份和幂等执行。

使用方法见 [外部审阅说明](../plugins/literature-translation/references/external-review.md)；旧项目升级见 [迁移说明](../plugins/literature-translation/MIGRATING.md)。

## 本机真实调用

以下结果来自独立的合成测试项目，包含源页面图片。模型和强度写入测试项目配置，未修改全局账号配置。

| CLI | 请求模型／强度 | 元数据中的实际模型／强度 | 结果 |
| --- | --- | --- | --- |
| Codex `0.158.0` | `gpt-6-luna`／`low` | `gpt-6-luna`／`low` | 调用、图片附加、身份核验、结果入库和门槛检查通过 |
| OpenCode `2.0.6` | `openai/gpt-6-luna#low` | `openai/gpt-6-luna`／`low` | 调用、图片附加、只读 agent 身份核验、结果入库和门槛检查通过 |
| Claude `2.1.284` | `sonnet`／`low`，身份配置为 `claude-sonnet-5-5` | `claude-sonnet-5-5`／未知 | 调用、图片读取、身份核验、结果入库和门槛检查通过 |
| Antigravity `1.2.12` | `gemini-3.1-pro`／`high` | 无 | 预期失败，记录为 `authentication`，随后成功回退到 Codex |
| Cursor | 模拟配置 | 无真实元数据 | 本机不可用，仅完成命令构造、解析、证据和失败路径模拟 |

最后一轮三种可用 CLI 的实测为 3 项通过；Antigravity 失败及回退另有 1 项通过。测试在父进程带有宿主会话标记时运行，确认外部调用仍使用独立会话。OpenCode 使用专用 agent，权限为默认拒绝、只允许读取，并从导出的会话记录核验实际 agent 和模型。

Antigravity 返回的具体原因是当前账号所在地区不具备使用资格。该结果属于账号访问失败，不代表 Antigravity 成功审阅。Cursor 未完成真实调用。

调用成功不等于内容获批。最终实测中，Claude 和 OpenCode 接受了合成译文；Codex 提出修改意见，外部门槛继续要求复审。Antigravity 回退测试故意使用错误译文，Codex 检出问题，门槛保持阻塞。Claude 元数据未给出实际强度，因此记录为未知。
